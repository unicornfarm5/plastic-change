# Guide and introduction to projec for AI agents
The project case is a campaign for NGO Plastic Change. 

## Site map
- Landing page: World Cleanup Day
- Participate as a school 
    – Registration page: register a class
    - A page where the teacher enter the amount of trash the class has collected. This suppage will not be open for navigation on first deployment. 
- Participate as a company 
    - Registration page for sponsors
    - "Thank you for your contribution" page. This subpage will only be navigated to from a button on Registration page for sponsors. 

## Style feel
- generel feel is light and modern

## Fonts generel use
- only use fonts from the fonts folder
- for H1 - use Campton SemiBold normally or evt Bold version
- for H2 - use Rubik in SemiBold
- for H3 - for under headings in body text use Rubik in medium-italic or 
- for P - use rubrik Rubik Light
- use Rubik sometimes when there is another color behind the text or when it is very small like image-description.
- On buttons use Rubik in Semibold
- Footer: uses rubik
